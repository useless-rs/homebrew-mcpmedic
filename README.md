# homebrew-mcpmedic

Homebrew tap for [mcpmedic](https://github.com/useless-rs/mcpmedic) — first aid for MCP configs.

## Install

```sh
brew tap useless-rs/mcpmedic
brew install mcpmedic
```

Or in one command:

```sh
brew install useless-rs/mcpmedic/mcpmedic
```

## What it does

mcpmedic scans, health-checks, diffs and syncs MCP server configurations across every AI coding tool you use (Claude Code, Cursor, Windsurf, VS Code, Zed, Codex CLI, Cline, Roo Code, Gemini CLI, opencode). Single static binary, no dependencies, no daemon.
